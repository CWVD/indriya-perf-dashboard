Field — real users (the trend Google ranks on)

28-day real-user p75 from CrUX. The whole-site figure is the headline; product/store pages aren't here because they rarely have enough traffic (they're covered under Lab). Refreshes weekly.

Lab — fresh test (spike / regression tripwire)

A test we trigger daily on the full page mix (homepage, PLPs, PDPs, store). Refreshes daily.

Read lab as a tripwire, not a measurement. These are throttled lab simulations — watch the direction and the pass/fail colour, not the absolute number. A lab LCP of 50 s does not mean real users wait 50 s; the whole-site Field figures above are the real-user truth.
Field = CrUX History API · Lab = PageSpeed Insights API · auto-refreshed by GitHub Actions.
